# Sicherung der Wehr

Unter **Einstellungen → Sicherung** sichert ihr die Daten eurer Wehr selbst, zusätzlich
zum Backup des ganzen Servers.

1. **Sicherungspasswort** festlegen (mindestens 12 Zeichen). Jede Sicherung wird damit
   verschlüsselt. Ohne das Passwort lässt sie sich nicht öffnen, also gut aufbewahren.
2. Uhrzeit und Aufbewahrung wählen. Glutnest sichert dann täglich; **Jetzt sichern**
   geht jederzeit.
3. Sicherungen lassen sich herunterladen und woanders aufbewahren.

Eine Sicherung enthält alle Daten und Dateien der Wehr, aber keine Passwörter,
Zwei-Faktor-Anmeldungen und kein Protokoll.

**Wiederherstellen** braucht den Code aus der Authenticator-App. Vorher sichert Glutnest
den jetzigen Stand, damit sich der Schritt rückgängig machen lässt. Schlägt etwas fehl,
bleibt alles wie vorher.
