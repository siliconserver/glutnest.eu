# Mitteilungen

Unter **Mitteilungen** verschickt die Wehrführung Nachrichten an die ganze Wehr, einen
Standort oder eine Gruppe. Sie erscheinen in Glutnest und auf Wunsch zusätzlich per
Mail, an Mitglieder ohne Konto an die Adresse im Personal. Jede Mail geht einzeln
raus, niemand sieht die anderen Empfänger.
